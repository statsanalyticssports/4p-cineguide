What this version can and cannot know

A screenshot is already tone-mapped by the camera/app, so this tool uses its pixels as a relative exposure check—not as an absolute lux meter. Exact recommendations are strongest when the current shutter, ISO, WB and ND state are known. Always verify the result with a second Mimo screenshot before an important take.
